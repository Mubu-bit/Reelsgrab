What you submit

The only thing you submit is the Instagram Reel link you paste. We don't ask for names, emails, passwords or an Instagram login. Don't paste anything other than a public Reel link.

What happens to the link

Your browser sends the link to ReelGrab's server (hosted on Vercel). The server checks it and forwards it to a third-party media-processing service, Apify, which looks up the public Reel and returns a temporary video link. We pass that link, and a preview image link if available, back to your browser.

Videos and previews

ReelGrab doesn't download, store or host video files. The video link and the preview image you receive point to files served by other parties (for example Instagram's content delivery network), not by us. When your browser loads them, those servers can see your IP address and device details, as with any website.

What may be recorded

  • Hosting provider: Vercel may keep standard technical logs (such as request time, IP address and requested path) for operations and security.
  • Our code: we don't intentionally log the Reel links you submit. Failed requests may record an error status code. Your IP address is held temporarily in the server's memory to apply request limits, and we don't write it to a database. Because the memory belongs to short-lived server instances, it is cleared when they restart or scale down.
  • Third-party service: Apify processes the submitted link and may keep records of the request and result under its own policies, which we don't control. See Apify's privacy policy.

Cookies and analytics

ReelGrab does not set cookies of its own. We use Vercel Web Analytics to count page views and visitors in aggregate, so we can see whether the site is used and which pages are visited. It records technical details such as the page visited, referring site, country, browser and device type, and it does not use cookies. We currently run no advertising scripts. If we add advertising (for example Google AdSense) in future, this policy will be updated first to describe the cookies and data involved and how to opt out.

Children

ReelGrab isn't directed at children under 13 and doesn't knowingly collect personal information from them.

Changes

We'll update this page and its date if the way ReelGrab works changes.
